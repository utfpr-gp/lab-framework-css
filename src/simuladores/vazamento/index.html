Vazamento Horizontal

Aquela barra de rolagem lateral que aparece só no celular — quem a causou, e como achar o culpado.

O conceito

É o bug mais comum de layout responsivo: no seu monitor está tudo perfeito, mas no celular aparece uma barra de rolagem horizontal e a página inteira "balança" para os lados. O motivo é sempre o mesmo — algum elemento é mais largo que a tela.

O que muda é o culpado. E ele costuma ser invisível: o elemento que vaza quase nunca é o que você vê estourando a borda, porque o pai dele pode estar escondendo a bagunça.

A solução que não é solução: jogar overflow-x: hidden no body. Isso não conserta nada, só esconde — o elemento largo continua lá, empurrando o layout, e de quebra você perde a rolagem em qualquer coisa que precisasse dela. É curativo em cima de fratura. Ache o culpado.

Como um profissional acha o culpado

A técnica é comparar, elemento por elemento, a borda direita dele com a borda direita do container. Quem passar, é o responsável. É exatamente isso que o simulador faz abaixo, e é o mesmo raciocínio que você repete no DevTools quando estiver sozinho com o problema.
